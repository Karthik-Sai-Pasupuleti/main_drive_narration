Action-based drive narration

One vision-language agent watches the car's forward view and narrates the driving action directly — describing the scene, restating the action, and speaking it in a single model call. No separate perception or fusion agents.

3 · Narration agent

vision · one model call
VLM agent · sees + narrates

Watch the view, convey the action

A single vision-language model reads the forward image together with the ground-truth driving action and context, then returns one warm, present-tense, first-person-plural sentence (≤ 14 words). The action is the ground truth it must convey; the image only grounds it in the road ahead.

Rule

Hazards are verified-only: the agent may name a pedestrian, cyclist or obstacle only if a drone / infrastructure report gives it — never one it merely thinks it sees in the image.

example narration “The vehicle is turning left through the intersection, following the clear lane ahead.”
