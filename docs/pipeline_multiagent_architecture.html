ROS 2 · RViz · vision-language pipeline

Multi-agent drive narration

Two vision agents read the scene from two RViz camera views; a text agent fuses their descriptions with the current driving action into one spoken sentence for the passenger.

3 · Perception agents

vision · run per event
Vision agent

Road-geometry

Traces the cyan road-edge lines in the BEV frame and describes the road shape ahead — straight, a gentle or sharp bend, a fork, an intersection.

in
BEV image narration_bev
prompt
road_geometry_description_prompt.toml
out
road_geometry · 1–2 sentences
example output “The road runs straight ahead for a short distance before bending gently to the left.”
Vision agent

Obstacles

Reports only the vehicles, cyclists and pedestrians around the ego — their type, side, and whether any sits inside the highlighted lane ahead.

in
front image narration_chase
prompt
obstacles_description_prompt.toml
out
obstacles_description · 1–2 sentences
example output “A pedestrian is on the left beside the corridor, not blocking the path.”
two descriptions + action + memory → fuse

4 · Narration agent

text-only · fusion
Fusion agent

Compose one spoken sentence

Fuses the ground-truth driving action with the two scene descriptions and short memory into a single warm, present-tense, first-person-plural line (≤ 14 words). The action is the ground truth the sentence must convey — geometry and obstacles only ground it.

inputs
driving_action road_geometry obstacles drone_data infrastructure_data action_memory narration_memory
prompt
narration_prompt.toml
out
Narration · one sentence
TURN LEFT (intersection) TURN RIGHT (intersection) SLOW DOWN (external report) GREETING
example narration “We're turning left as the road curves gently ahead.”

5 · Outputs

speech + eval logging
Live

Speech & memory

  • Neural TTS (kokoro) speaks the sentence to the passenger.
  • The line is appended to narration_memory so the journey stays coherent.
Eval mode

MLflow + CSV

  • One run per event: the two input images, all three text outputs.
  • Per-agent latency road_s obstacles_s narration_s → mlflow.db + eval/*.csv
Each agent is an independent LLM + prompt, configured per role in src/configs/multi_agent_pipeline.toml — provider ollama or openai, model swappable per agent (road / obstacles / narration). Shared front-end (trigger detection + capture) feeds a serial worker so events narrate one at a time.
